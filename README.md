# scaff-js

A CLI tool for quickly scaffolding web projects from an interactive project configuration.

## Overview

**scaff-js** is a command-line scaffolding tool that helps developers create a project structure by interactively configuring the framework, page sections, and components they want to use.

Instead of manually setting up the same project structure and boilerplate, Scaff guides you through the setup process and generates the required project configuration.

## Installation

Install Scaff globally using npm:

```bash
npm install -g scaff-js
